# 语音功能

AI 自动发语音默认是关的。是否启用由管理员在二代仿真配置中控制，并受音频库、发送权限、限频与发送回执检查约束。

项目内的 `src/voice-core.js` 提供音频检查、处理和发送共享实现。编码或音量处理可能需要 FFmpeg；离线测试不代表真实 QQ 已接受语音。

部分安装另外提供位于相邻 `voice-tool/` 目录的独立语音工具：命令行入口 `voice-cli.mjs`，图形界面入口 `voice-gui.mjs`，Windows 启动文件通常名为 `发语音-图形界面.cmd`。这些辅助工具不包含在本仓库中，缺少该目录时请勿假定这些入口已经安装。

当前项目的自动化验证会区分共享内核与可选独立工具。实际上传和 QQ 发送需要使用已安装工具及有效账号进行验证，不能用脚本结构检查替代。
