# 人物记忆 1.6.0

本版保留现有 SQLite、真实 QQ、机器人和会话范围及管理员核实流程。没有接入另一套全局 DSH 记忆或额外模型。

## 检索

- 新增 SQLite `memory_search_documents`、`memory_search_terms` 两张派生表，以中文二元词和英文词检索，先召回再限制候选数，避免旧记录被最近 120 条挤出。
- 服务首次打开旧库时事务补建索引；新增、管理员纠正和更正同步维护索引。原始记录、来源、审核、版本和关系分不改写。
- 检索结果仍受当前白名单、机器人、群/私聊、人物状态、来源有效期和派生链检查。
- query/profile 可选 topic：game、reading、study、work、daily。主题可重叠，不作为授权依据；关键词不做语义同义推断。

## 已确认与观察

`qq_social_memory_remember` 的 confirmed=true 只有在正文与规则识别出的本人明确自述一致、kind 匹配时才生效；不支持的改写或复杂事实降为 proposed，并返回 confirmationDowngraded。可选 evidence 必须逐字来自原消息，但“证据存在”本身不能授权确认任意推断。

来源作者显式写为人物主体。敏感凭据和提示词指令拒绝入库。规则补充拒绝反讽“才怪”等；仍不是完整自然语言语义校验。已确认表示本人明确说过或管理员核实，不代表外部调查核实。

仅 `origin=qq-agent`、kind=experience、proposed 的当前消息作者观察进入普通索引，标 observation、confirmed=false，不进入已确认事实或关系评分。旧导入待核实资料继续由管理员审核，不自动混入观察通道。

新模型候选默认 30 天有效；明确当前学习/准备等自述为 90 天，其他通过校验的稳定自述不附加有效期。旧记录不批量改动。

## 摘录与去重

`qq_social_memory_profile(messageId,query?,topic?)` 按真实作者和当前会话给出最多 3 条已确认资料、1 条观察，每条正文最多 100 字，附 memoryId、版本、来源消息、状态和主题。它是按需计算的原句摘录，不生成性格结论、不调用额外模型、不保存会过时的二次摘要；遗忘、到期、撤权会立即反映。不会按昵称合并人物，也不会读取其他群或私聊。

模型补记/自动新写可按同人物、同会话、同类型和归一化正文去重；模型补记的合并会保留来源消息。不推断同义，保留小数与正负号。已遗忘内容不会因新消息中的同一归一化正文而复活。

## 原生可选记忆

一并验证并部署本地已有的 405 修复：只有认证插件清单确认 meow-memory 缺席时，将 405 记为 unavailable；插件已存在、清单无效、发现失败或 unknown session 仍报隔离失败。缺席结果短时缓存，后续安装会重新检查。

## 验证与回滚

新增 `scripts/test-memory-retrieval-v16.mjs`，纳入 npm test。使用隔离临时库与模拟服务，不向 QQ 发消息。

生产升级前停止 DSH/bridge、备份本次覆盖文件，并用 SQLite backup API 保存 5 个记忆库；保存 SHA-256 清单。部署后核对记忆记录、来源、审核、关系账本未被迁移改写，检查数据库、扩展版本、工具注册、QQ 链路及检索只读调用。

回滚先停止 bridge/DSH，恢复源码文件。新增索引表是派生数据，旧代码不会使用；若必须回退数据库到备份时点，应先另存升级后的最新库，避免丢弃新对话产生的数据。不要直接用旧备份覆盖正在运行的数据库。

限制：尚未进行长期记忆质量/真实账单/压力测试；自动自述规则保守，模型是否实际选择新工具仍需真实聊天观察；管理记忆面板当前仍主要在内存中筛选分页，大规模整库管理读取可另行优化。
