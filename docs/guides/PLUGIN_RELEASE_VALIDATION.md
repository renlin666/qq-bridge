## 应用与回滚

正常运行入口为 `npm start`。已有安装保留原 `config.json` 和 `state/`，无需清空消息、会话或发送账本。更新后重启桥接并重连现有 QQ MCP；不需要给 DSH 安装新的插件包。建议先只启用已有功能，再在测试会话安装 echo 示例。

故障时先将有问题的 `extensions.<id>.enabled` 设为 `false`。管理页停用会立即清理插件任务；恢复启用需要重启。要退回整个程序，应另取改造前基线分支的代码目录并使用 `npm ci`，然后在停机状态下接回已有本地配置与状态。

不要用 `git clean -fdx` 或清空 `state/` 做回滚；这会删除配置和幂等账本。空间发布/评论与联系人发送沿用原账本路径，升级不重置待核实请求，回滚也应保留这些文件。
